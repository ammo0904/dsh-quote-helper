# DSH 引用助手（Chrome 擴充套件 V1）

在 DSH 網頁介面的對話區**框選任何文字**，選取處旁就會浮出「引用」小按鈕；
按一下，框選的內容立刻被送進下方輸入框（游標位置），不用再複製貼上。

---

## 一、安裝（只需做一次）

1. 開 Chrome，網址列輸入 `chrome://extensions` 按 Enter。
2. 右上角打開 **開發人員模式**（Developer mode）。
3. 左上角點 **載入未封裝項目**（Load unpacked）。
4. 選擇這個資料夾：`DSH引用助手-V1`（就是本說明檔所在的那個資料夾）。
5. 清單出現「**DSH 引用助手**」即安裝完成。

> 安裝後若 DSH 網頁已經開著，請按 `F5` 重新整理一次頁面。

## 二、使用方式

1. 在 DSH 對話區用滑鼠選取一段文字（回答、你的訊息、工具輸出、程式碼區塊都可以）。
2. 選取範圍旁會出現黑底白字的 **引用** 按鈕。
3. 點它 → 這段文字就出現在下方輸入框裡（接在原本草稿後面）。

- 想取消：按 `Esc`，或在空白處點一下。
- 要接多段：可以連續引用好幾次，內容會依序累加。

## 三、設定（點工具列上的擴充套件圖示）

| 設定 | 說明 |
| --- | --- |
| **啟用引用按鈕** | 關掉就完全不顯示按鈕。 |
| **顯示範圍** | `只在對話區`（預設，建議）＝只有在對話訊息上框選才出現；`整頁任何位置`＝連側邊欄、右側面板的文字也能引用（輸入框本身一律排除）。 |
| **插入格式** | `原文照貼`（預設）＝原樣送進輸入框；`Markdown 引用`＝每行前面加 `>`，在對話裡顯示成引用區塊。 |

設定改完**立即生效**，不用重新整理。

## 四、運作原理（給未來的自己看）

- DSH 的輸入框是 **Lexical** 編輯器（`<div data-composer-input contenteditable>`），
  不是普通的 `<textarea>`，所以不能直接改 `value`。
- 擴充套件以 **MAIN world** 內容腳本注入，直接取用 Lexical 掛在 DOM 上的
  `rootElement.__lexicalEditor` 實例，用和 DSH 內建「貼上」相同的路徑插入文字：
  `editor.update() → selection.insertText(text)`（`discrete: true` 同步提交）。
- 若上述路徑失效（例如 DSH 換了編輯器版本），會依序退回：
  合成 `paste` 事件（帶 `clipboardData`） → `document.execCommand('insertText')` →
  直接改 DOM，每一步都會驗證文字是否真的進去，失敗才換下一招。
- 設定值透過 `<html>` 上的 `data-dshq-*` 屬性，由隔離世界（ISOLATED）的
  `content/bridge.js` 從 `chrome.storage.local` 同步過來。

## 五、疑難排解

- **完全沒看到按鈕**
  1. 確認網址是 `http://127.0.0.1:3080`（或 `localhost` 開頭）。本擴充套件只在這兩種主機上生效。
  2. 到 `chrome://extensions` 確認擴充套件是「已啟用」，且沒有顯示錯誤。
  3. 重新整理 DSH 頁面。
- **DSH 換了連接埠或改用其他網址**（例如公司用 `http://192.168.1.x:3080`）
  編輯 `manifest.json`，在 `content_scripts` 的兩個 `matches` 陣列各加一行該網址的樣式
  （例：`"http://192.168.1.*/*"`），存檔後回 `chrome://extensions` 按重新載入。
- **按了引用沒反應，右下角跳出紅色提示**
  表示找不到輸入框（例如還沒開啟任何對話），先開一個對話再試。
- **想回報問題**：按 `F12` 開 Console，看有沒有 `DSH 引用助手` 相關訊息。

## 六、已知限制

- 只支援 DSH 網頁版（本機 `127.0.0.1` / `localhost`）；DSH 桌面殼或用其他網域發佈的版本不在範圍內。
- 引用插入**不會**自動加上「來源／訊息編號」，需要出處請自行補述。
- DSH 若大幅改版把 `data-composer-input` 或 Lexical 內部結構換掉，可能需更新此擴充套件。
